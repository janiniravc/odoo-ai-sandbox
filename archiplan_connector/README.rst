ArchiPlan Connector
===================

Connect Odoo sales data to ArchiPlan using a dedicated read-only internal user.
Configure the ArchiPlan URL and view-only schedule link in Settings, then use
Create ArchiPlan access to generate credentials for Orders → Import → From Odoo.

The ArchiPlan Schedule page is available under Manufacturing → Planning.

The ArchiPlan user is an internal user; on Odoo Enterprise / Online it counts
as one user and has read-only rights to sales orders and products.
