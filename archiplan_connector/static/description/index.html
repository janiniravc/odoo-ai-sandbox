Import Odoo sales orders into ArchiPlan, plan people and machines, and review production schedules in Manufacturing.

Features

  • Import selected Odoo sales orders with status and creation date filters.
  • Preview products, quantities, and customer references before importing.
  • Plan production steps across people and machines in a schedule chart.
  • Open a step to review its order, timing, and resource assignment.
  • Configure read-only Odoo access for ArchiPlan.

Setup

  1. Install ArchiPlan Connector in Odoo.
  2. Open Settings and configure the ArchiPlan URL and view-only schedule link.
  3. Use Create ArchiPlan access to generate credentials for a dedicated read-only internal user.
  4. In ArchiPlan, open Orders → Import → From Odoo and connect with the generated access details.
  5. Select orders, review the import preview, and import them into ArchiPlan.
